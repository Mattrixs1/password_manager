
# Password Manager

It's a password manager made in python that stores you're passwords unencrypted in a .yaml-File.
## Set up

Copy or downloud the ```passwordmanager.py``` 
and put it in a folder.
Make sure that [Python](https://www.python.org) and pyYAML are installed:

```bash
 python --version
```

```bash
 pip install PyYAML
```
When running it the first time a folder should appear with a ```passwords.yaml``` inside of it 
WARNING: DO NOT SHARE THE .yaml-File,
it has all you're informations unencrypted in it
